# Proveniência da base oficial

O V3 original foi preservado byte a byte no arquivo privado do responsável. A distribuição pública 1.4 conserva seu fingerprint em `original-provenance.json`. O ZIP original contém contexto criativo privado e não acompanha esta distribuição. Um hash público identifica a base, mas não demonstra sozinho o conteúdo ou a disponibilidade do original.

O schema operacional atual tem 35 entidades. Não restaurar versões históricas sobre uma produção. Consultar, migrar e reconciliar explicitamente. Versões anteriores e o backup Git privado foram preservados antes do saneamento público.

# Reference analysis

Use authorized materials. Begin with the purpose of the reference (narrative mechanism, performance, tension, pacing, sound or distribution). Never assume the user wants to copy it. Analyze at an appropriate granularity and separate observation from interpretation.

Record source, access date, episode duration, evidence type, and whether view/like or audience-retention numbers are actually available. Mark unavailable facts as unknown. Map the opening event, first question, goal and opposing force, decisive changes, emotional anchors, payoff and ending. For footage with usable timestamps, record shot changes, speech and silence, transitions, and how new information changes interpretation. If measuring pace, state method and sample. For existing retention graphs, map changes to observed time ranges with confounders. For audio, distinguish actual audio analysis from inferred intent.

Extract only generalizable methods: e.g. opening a situation mid-change, character knowledge asymmetry, contrasting emotional states, a cut following a meaningful reaction, an earned reveal. Do not reproduce protected dialogue, sequence, distinctive plot or shot-for-shot composition. Translate the method into an original alternative that fits this project's world. Describe what to test and why it might fail. Source popularity is not proof that a particular technique caused it.
